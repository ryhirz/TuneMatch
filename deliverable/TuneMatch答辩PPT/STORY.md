# TuneMatch 答辩 PPT 叙事逻辑

## ① 用户意图对齐
- **目标受众**：课程答辩评委/老师
- **核心目标**：讲完后让评委记住——「这是一个功能完整、数据真实、有创新点的 AI 音乐推荐平台」；核心记忆点 = 777 首真实曲库 + 多模态 AI 推荐 + 可解释匹配度 + 歌单画像社交预演
- **PPT 长度**：12 页（含封面/目录/结束页）→ Hero 页 3 页（封面、数据成果、结束页）
- **视觉调性**：科技感 / 现代 / 蓝紫渐变 / 音乐律动
- **内容边界**：必讲 = 项目背景、功能演示、技术架构、数据成果、创新点、运行方式；不讲 = 繁琐实现细节

## ② 页面布局骨架
- 章节：①封面 ②目录 ③项目背景 ④功能总览 ⑤核心流程(功能演示) ⑥技术架构 ⑦曲库数据(hero) ⑧创新点 ⑨测试验证 ⑩运行指南 ⑪总结展望(hero) ⑫结束页
- Hero 页：封面(1)、曲库数据(7)、总结展望(11)、结束页(12) → 4/12 = 33%（合理，答辩需要节奏）
- 目录 4 章 → 4 个 section 扉页：③背景 ⑤功能 ⑥架构 ⑦数据（用不同色块区分）
- rhythm：封面 peak → 目录 valley → 背景 valley → 功能 peak → 流程 supporting → 架构 supporting → 数据 peak → 创新 supporting → 测试 supporting → 运行 valley → 总结 peak → 结束 transition
