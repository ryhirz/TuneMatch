# TuneMatch 答辩 PPT 设计稿

## 画布与母版
- 画布：1280×720，上下 padding 20px，左右 padding 64px
- 三区母版：A 标题块 0-120px（标题 36px bold）/ B 内容区 120-660px / C 页脚条 660-720px（页码 14px 灰）
- 封面/章节/结束页可自定义版式

## 色板（≤4 hex）
| 角色 | 色值 | 用途 |
|------|------|------|
| 主色 | #0071E3 | 标题、主按钮、强调数字、图表主系列 |
| 辅色 | #7C3AED | 渐变辅端、章节块、副标题 |
| 强调色 | #FF6B9D | 焦点数据、高亮徽章、hero 数字 |
| 中性色 | #1D1D1F / #6E6E73 | 标题文字 / 正文灰字 |
- 渐变方案：linear-gradient(135deg, #0071E3, #7C3AED) 用于封面背景/卡片头部/hero 块
- 半透明：rgba(255,255,255,0.9) 白卡片盖在渐变上；rgba(0,0,0,0.35) 蒙版

## 字体系统
| 层级 | 字号 | 字重 |
|------|------|------|
| 封面主标题 | 88px | bold |
| 章节大字 | 64px | bold |
| 巨型数据 | 72-96px | bold |
| 页面标题 | 36px | bold |
| 卡片标题 | 22px | semibold |
| 正文 | 18px | regular |
| 页脚 | 14px | regular |
- 字体：思源黑体/微软雅黑（中）+ Inter（西文数字）
