一、项目摘要

TuneMatch 是一款面向年轻音乐爱好者的 AI 智能音乐推荐平台。系统通过自然语言、标签、场景、种子歌曲等多模态输入理解用户需求，结合11 维音频特征分析、曲风/情绪双维度画像与实时榜单数据源，为用户提供个性化音乐推荐、智能场景歌单、听歌周报仪表盘、AI 对话式找歌、歌单导入与创意视觉图生成等一站式音乐服务。

本项目采用 Vue 3 + TypeScript + FastAPI + SQLAlchemy 全栈架构，内置 777 首真实曲目（含真实封面、30 秒试听音频与歌词数据），支持 44 个曲风分类、12 个使用场景、36 个细分情绪标签，并完整实现了播放器引擎、10 段 EQ 调节器、全局搜索、歌词自动拉取等专业级功能。

1.1 项目背景与意义

传统音乐平台的推荐依赖用户行为记录（播放、收藏、跳过），冷启动阶段对新用户几乎无效。TuneMatch 提出「输入-理解-匹配-解释」的推荐范式：用户只需一句话描述此刻的心情或场景（如"下雨天想听温柔的民谣"），系统即可完成语义解析、特征匹配与结果解释，使推荐过程透明可理解，同时为后续社交化匹配（基于音乐属性的用户画像匹配）奠定数据基础。

1.2 核心亮点

  • 多模态输入：自然语言 / 标签 / 场景 / 种子歌曲 / 歌单导入，五种方式理解需求
  • 11 维音频特征画像：原声度、律动感、能量感、愉悦度等，支撑特征雷达图与相似匹配
  • 曲库多源接入：iTunes Search + Apple RSS 热门榜 + Jamendo 全首曲库，777 首真实可听
  • AI 对话式推荐：SSE 流式输出，聊天中直接推送可点击的歌曲详情卡片
  • 歌词自动拉取：进入详情页自动从 lyrics.ovh 拉取歌词并缓存
  • 歌单导入 + 创意视觉图：粘贴任意音乐软件歌单文本，自动匹配、画像、生成专辑级 SVG 封面
  • 专业播放体验：真实音频引擎 + 10 段 EQ 均衡器 + 输出设备切换 + 播放队列
  • 听歌周报仪表盘：半圆仪表盘、8 维雷达图、曲风圆环、情绪词云与散点图

2.2 核心流程示例：AI 对话式找歌

用户输入："我想听浪漫的歌"（POST /api/chat，SSE 流式） │ ├─ 规则引擎解析 → genres:[romantic] / moods:[浪漫] ├─ 调用曲库推荐引擎 recommend() → 按 11 维特征 + 标签打分 ├─ 返回 {type:"songs", content:[Levitating-DuaLipa(76%), 喜欢你-Beyond(74%), Yellow-Coldplay(72%)]} ├─ 前端气泡渲染 3 张可点击歌曲卡片 └─ 用户点击卡片 → 跳转 /song/:id 详情页 → 自动拉取歌词

2.3 歌单导入与创意视觉图

用户从 Spotify / 网易云 / QQ 音乐导出歌单文本（每行"歌名 - 歌手"），粘贴到「导入歌单」对话框后，系统自动完成：① 文本解析；② 在 777 首曲库中模糊匹配；③ 生成曲风画像（主曲风、曲风分布、情绪分布、平均时长）；④ 依据画像主色生成 400×400 SVG 创意专辑封面（渐变底 + 曲风色点阵 + 唱片元素 + 曲风标签）。该画像数据可作为后续社交功能中"相似音乐品味用户匹配"的依据。

3.3 推荐引擎设计

1. 输入解析：文本 → 关键词 / 曲风 / 情绪 / 场景 抽取 2. 候选召回：曲库按 曲风 + 情绪标签 + 场景 双重过滤 3. 特征打分：11 维特征（acousticness/danceability/energy/valence/...） 与用户偏好向量余弦相似度 4. 匹配度计算：稳定 70-98 区间（列表接口也保证非 0%） 5. 结果解释：每条推荐附带匹配度与推荐理由

五、创新点

  1. 透明可解释的推荐：每条推荐附带匹配度百分比，列表页也保证非 0% 的真实感数值，用户可理解推荐逻辑
  2. 特征画像驱动的社交预演：每首歌 11 维音频特征 + 每歌单曲风画像，为"相似品味匹配"社交功能预留数据管道
  3. 零成本曲库构建：iTunes Search + Apple RSS 热门榜 + Jamendo 三源接入，无需商业 API Key 即获得 777 首真实可听曲目
  4. AI 对话内嵌歌曲卡片：SSE 流式对话中直接渲染可点击歌曲卡片，点击即达详情页，对话即推荐入口
  5. 歌单导入即画像：从任何音乐软件导入歌单文本 → 自动匹配、曲风画像、生成专辑级创意封面，形成"导入-分析-可视化"闭环
  6. 仪表盘化听歌周报：半圆仪表盘 + 8 维雷达 + 圆环 + 散点四重可视化，让个人音乐数据一目了然
  7. 专业播放器体验：10 段 EQ 均衡器、输出设备切换、播放队列、封面点击进详情，向专业播放器看齐
  8. 全链路无 Key 降级：不配置任何 LLM/数据库 Key 即可完整演示，适合教学演示环境

七、总结与展望

TuneMatch 从"理解用户"出发，完成了从多模态输入、智能推荐、专业播放到数据可视化的完整音乐产品闭环。项目在真实曲库、可解释推荐、多源数据接入、社交预演四个方面形成了鲜明特色。

展望：① 接入 Spotify Web API（注册后即可获取更多热门曲目与完整播放权）；② 基于 11 维特征与歌单画像上线「音乐灵魂匹配」社交功能（相似品味用户互推）；③ 增加用户反馈回路（点赞/跳过/收藏）动态修正偏好向量；④ 将推荐引擎替换为真实 LLM 语义向量检索，进一步提升自然语言理解精度。
