## 项目核心数据

- **曲库**：777 首真实歌曲（100% 可试听，774 首带封面，144 首带歌词）
- **分类**：44 个曲风分类、36 个情绪标签、12 个使用场景
- **测试**：后端 pytest 45/45 通过，前端 Vitest 4/4 通过，构建零错误
- **技术栈**：Vue 3 + TypeScript + FastAPI + SQLAlchemy + 多源数据接入

## 一键启动

```bash
# Windows：双击 start-tunematch.bat
# 前端 http://localhost:5173 · 后端 http://localhost:8000
```
